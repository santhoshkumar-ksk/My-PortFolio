# Santhosh Kumar — Portfolio Website

A responsive dark-modern portfolio built with plain HTML, CSS and JavaScript.

## Files
- `index.html` — page content and direct contact links
- `style.css` — responsive dark theme and layout
- `script.js` — mobile navigation and current year

## Run locally
1. Extract the ZIP file.
2. Open `index.html` in a modern browser.

No build tools or package installation are required. Google Fonts are loaded from Google Fonts when internet access is available; system fallback fonts are provided.

## Publish online
You can publish this folder using GitHub Pages:
1. Create a GitHub repository (for example, `santhosh-portfolio`).
2. Upload `index.html`, `style.css`, and `script.js` to the repository root.
3. Open repository Settings → Pages.
4. Select Deploy from a branch, choose `main` and `/ (root)`, then Save.
